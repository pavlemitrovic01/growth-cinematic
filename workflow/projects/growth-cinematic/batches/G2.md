članke i 404 probu. `G1` je jedini ostao na užem spisku.

**Isto pravilo po kom je `G1` išao ispred `M2`:** kapija pokriva površinu **pre** nego što se
površina menja. Pavlova odluka 2026-09-09.

## Plan

Jedan **izveden** spisak na vrhu test fajla, koji oba testa koriste:

```js
import { PAGE_PATHS } from '../lib/routes.js';
import { allPostSlugs } from '../lib/posts.js';   // :282, već postoji

const GATED_ROUTES = [
  ...PAGE_PATHS,
  ...allPostSlugs().map((s) => '/truckers-lounge/' + s),
  '/missing-page',
];
```

⚠️ **Izvodi se, ne prekucava** — isti razlog koji `lib/routes.js` navodi u svom zaglavlju:
*„provera koja broji ne vidi ono čega nema"*. Četvrti članak ne traži izmenu kapije.

⚠️ **`/missing-page` vraća 404, ne 200.** Tvrdnje A i B rade nad telom odgovora bez obzira na
status. Test to mora reći **izričito**, da neko kasnije ne „popravi" spisak izbacivanjem 404 —
a `app/not-found.tsx` renderuje `PageShell` kao i svaka druga stranica.
